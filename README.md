# Eng-muzzamil63-Portfolio

Muzzamil Ansari | Portfolio Website
A modern, responsive, and production-grade developer portfolio built with Tailwind CSS, featuring a dynamic multi-theme system (supporting multiple dark and light color combinations), interactive architectural layouts, and streamlined professional sections tailored for an AI Engineer and Full-Stack Developer.

Features
Interactive Theme Switcher: Instantly toggle between multiple distinct color palettes and modes (Classic Dark, Midnight Blue, Obsidian Black, Dark Emerald, Light Slate, Soft Rose, Mint Emerald, and Sunset Amber) with persistent preferences stored in localStorage.

Professional Roles & Capabilities: Clearly outlines engineering expertise across Full-Stack Applications, AI-Powered Applications, Agentic AI Systems, Enterprise RAG, Document Intelligence, and AI Automation.

Problem-First Architecture: Highlights concrete enterprise and business problems alongside technical solutions (e.g., Document Intelligence pipelines, RAG implementations, and LLMOps evaluation layers).

Architecture & Stack Breakdown: Visualizes the full-stack lifecycle and AI engineering stack using clean glassmorphism UI components.

SEO & Metadata Optimized: Includes structured JSON-LD schema for search engines, Open Graph tags, and responsive mobile-first navigation.

Tech Stack
Frontend Framework / Styling: HTML5, Tailwind CSS (via CDN with custom configuration)

Typography: Inter & JetBrains Mono (Google Fonts)

Interactivity: Vanilla JavaScript (Theme management, responsive navigation states)

Hosting / Deployment: Static hosting ready (GitHub Pages, Vercel, Netlify)

Quick Start & Setup
Clone the repository:

Bash
git clone https://github.com/Eng-muzzamil63/muzzamil.dev.git
cd muzzamil.dev
Run locally:
Simply open the index.html file in any modern web browser, or serve it using a local server extension (like Live Server in VS Code).

Customization
Links & Contact: Update your email or external profile links directly within the HTML file anchors (mailto:engmuzzamil63@gmail.com, GitHub, and LinkedIn).
